# 外国人材募集企業バンク（求人サイト）

日本で働きたい外国人と、その人を支える送り出し機関に向けて、外国人材を募集している企業を紹介するサイトです。
日本に住んでいて転職したい人と、海外からこれから日本に来る人の、両方に向けています。

- 公開先：https://imura451.github.io/jobs/（一覧）／ `…/jobs/c/<企業ID>.html`（各企業）
- 言語：やさしい日本語（ふりがな付き。ボタンで消せます）／English
- 運営：株式会社Minobordo（ガイコクジンコネクト）
- 姉妹サイト：人材バンク https://imura451.github.io/candidates/

> **公開の前に**：求人を載せて応募を受け付ける仕組みは、内容によって**職業紹介**（許可・届出が必要）にあたります。
> 運営の根拠を愛知労働局に確認し、許可番号などを `data/settings.json` の `license.text` に入れてから公開してください。

## 新しい企業を足す

1. `data/companies/sample-01.json` をコピーして、`data/companies/<企業ID>.json` という名前にします
   - 企業ID は**半角の小文字・数字・ハイフンだけ**（例：`obu-kaigo`）。URLになるので、**公開したら変えません**
2. ファイルを開き、`id` を企業IDと同じにします
3. `"sample": true` の行を消します
4. 中身を書き換えます。項目の意味は `data/_書き方.md` にあります
   - 日本語は**やさしい日本語**で書きます。`漢字{かんじ}` と書くと、ふりがなが付きます
   - **分からない項目は空（`""`）のまま**にします。空の項目はページに出ません
5. 写真があれば `assets/companies/<企業ID>/` に入れ、`company.photos` にファイル名を書きます
6. 社長インタビューを YouTube に**限定公開**で上げ、`video` に動画ID か URL を書きます
7. 手元で確かめます（下の「手元で確認する」）
8. GitHub に送ります。数分後に公開されます

### 募集を終える

- `status` を `"募集終了"` にして送ります。一覧から外れ、企業のページに「募集を終了しました」と出ます
- `deadline`（募集の期限）を書いておけば、**期限の翌朝に自動で募集終了**になります（毎朝6時に作り直しています）
- 企業のページは消えません。SNSで広まったURLが「見つかりません」にならないためです

## 設定（data/settings.json）

| 項目 | 中身 | いま |
|---|---|---|
| `searchEngines` | 検索エンジン（Googleしごと検索を含む）に載せるか | **`false`**（載せない） |
| `showSamples` | サンプル企業を出すか | **`true`** |
| `license.text` | 職業紹介の許可番号など。フッターに出ます | **空** |
| `messengers` | LINE・Messenger・Zalo・WhatsApp のURL | LINEだけ |
| `form.endpoint` | 応募フォームの送り先 | 会社サイトと同じ受け口 |

### 本番の企業を載せたら

1. `showSamples` を `false` にする（サンプルが消えます）
2. 労働局への確認が済んだら `license.text` を入れ、`searchEngines` を `true` にする
   - 本物の求人のページにだけ、Google しごと検索用の情報（JobPosting）が入ります。サンプルには入れません
   - 募集終了の求人は、期限（validThrough）を過去の日付にして、Google の決まりに沿って外れるようにしています

## 手元で確認する

```
node build.js
python -m http.server 8767 --directory docs
```

ブラウザで http://localhost:8767/ を開きます。

`node build.js` は、データの書き間違い（カンマの付け忘れなど）があると、**何行目の何文字目か**を日本語で知らせます。

## ネットに公開する（GitHub Pages・無料）

人材バンク・空き家の管理人と同じ仕組みです。

### 最初の1回だけ

1. GitHub（アカウント Imura451）に、`jobs` という名前で保存先を作ります（**Public**、README などは付けない）
2. このフォルダを、その保存先につなぎます
3. GitHub の Settings → Pages → Source を **GitHub Actions** にします

### 2回目から

ファイルを直して GitHub に送るだけで、数分後に自動で公開されます。`docs/` は送る必要はありません。

---

## 応募フォームの届け先

会社サイト・人材バンクと同じ受け口に送られ、**Gmail と Lark の両方に届きます。**
通知の「送信ページ」に `求人サイト（ja）` のように出ます。「種類」に、求職者・送り出し機関・企業のどれかが出ます。

---

## 言語を足す（ベトナム語・インドネシア語・ネパール語・ミャンマー語など）

1. `lang/en.json` をコピーして `lang/vi.json` などを作り、右側の文を訳します
2. `build.js` の `const LANGS = ['ja', 'en'];` に `'vi'` を足します
3. 企業データの文章に `"vi": "…"` を足します。無い項目は日本語で代わりに出ます

`/vi/` の下に、同じ構成のページができます。
