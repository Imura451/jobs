# 企業データの書き方（data/companies/<企業ID>.json）

1社につき1ファイルです。いちばん早いのは、`sample-01.json` をコピーして中身を書き換える方法です。

## 文章の書き方

- **3つの言語で書く項目**は `{ "ja": "…", "en": "…" }` の形です。英語が空なら、日本語で代わりに出ます
- 日本語は**やさしい日本語**で書きます。短い文、むずかしい言葉を使わない、単語のあいだに空白
- **ふりがな**は `漢字{かんじ}` と書くと付きます。ふりがなが付くのは `{` の**直前に続く漢字だけ**です
  - `介護{かいご}` → 介護（かいご）
  - 数字のあとの漢字は、漢字の部分だけに付きます。`2人{にん}`、`10分{ぷん}` のように書きます
- 改行したいところは `\n` と書きます

## 全体

| 項目 | 書くこと |
|---|---|
| `id` | 企業ID。**半角の小文字・数字・ハイフンだけ**。URLになります（`c/<id>.html`）。**公開したら変えない** |
| `sample` | 架空のサンプルなら `true`。本物の企業には書きません |
| `published` | 載せるなら `true`。一時的に隠すなら `false`（ページも作られません） |
| `status` | `募集中`／`選考中`／`募集終了` のどれか |
| `postedAt` | 掲載日（`2026-10-01` の形） |
| `updatedAt` | 最終更新日。**直したら必ず今日の日付に** |
| `deadline` | 募集の期限。**過ぎると、status を変えなくても自動で募集終了**になります。決まっていなければ `""` |

### 募集終了の扱い

- `status` を `募集終了` にするか、`deadline` を過ぎると、**一覧から外れます**
- 企業のページは消えません。上に「この求人は募集を終了しました」と出て、応募ボタンが押せなくなります。SNSで広まったURLが「見つかりません」にならないためです
- `選考中` は一覧に残り、「選考中」の印が付きます。応募は受け付けます

## company（会社の紹介）

| 項目 | 書くこと |
|---|---|
| `name` | 会社名 |
| `business` | 事業の内容 |
| `employees` | 従業員の数（数字だけ） |
| `foreignStaff.count` | 外国人スタッフの数（数字だけ） |
| `foreignStaff.countries` | 国籍と人数 |
| `website` | ホームページのURL。無ければ `""` |
| `photos` | 職場の写真のファイル名。`assets/companies/<id>/` に置きます。**1枚目がSNSでシェアしたときの画像**になります |

## location（働く場所）

| 項目 | 書くこと |
|---|---|
| `prefecture` | 都道府県（`愛知県` のように、県・府・都まで）。地域の絞り込みに使います |
| `city` | 市区町村 |
| `station` | 最寄り駅と行き方 |
| `mapQuery` | 地図で表示する場所。**番地までは書かず、町名くらいまで** |

## job（仕事）

| 項目 | 書くこと |
|---|---|
| `field` | 特定技能の分野。下の16分野のどれか |
| `title` | 職種（例：介護スタッフ） |
| `description` | 具体的な仕事の内容 |

16分野：介護／ビルクリーニング／工業製品製造業／建設／造船・舶用工業／自動車整備／航空／宿泊／自動車運送業／鉄道／農業／漁業／飲食料品製造業／外食業／林業／木材産業

## 在留資格と、応募できる人

| 項目 | 書くこと |
|---|---|
| `visas` | 募集する在留資格。`特定技能1号`・`特定技能2号`・`育成就労・技能実習`・`技人国` から |
| `accept.inJapan` | 日本に住んでいる人が応募できるなら `true` |
| `accept.overseas` | 海外から応募できるなら `true` |
| `fromStatus` | **応募できる今の在留資格**。1つずつ `{ "status": "…", "field": "…", "noExam": true }` |
| `noExamNote` | 試験なしで移れるかの説明 |
| `leadTime.inJapan`・`.overseas` | 入社までの目安（国内／海外を分けて） |
| `interview.methods` | `対面`・`オンライン` |
| `interview.weekendNight` | 土日・夜の面接ができるなら `true` |
| `interview.travelCost` | 面接の交通費 |

`fromStatus` の `status` に書ける言葉：特定技能1号／特定技能2号／技能実習2号修了／技能実習3号修了／技能実習中／留学／技人国／特定活動／家族滞在／その他

`field` を `""` にすると「分野は問いません」と出ます。**試験なしで移れるかどうかは、制度上の判断なので、企業・支援機関に確かめてから書いてください。**

## video・imuraComment

| 項目 | 書くこと |
|---|---|
| `video` | 社長インタビューの YouTube の動画ID か URL。**「限定公開」か「公開」**にしてください（「非公開」だと見られません） |
| `imuraComment` | 井村さんが会社を訪問・面談して感じたこと |

## terms（求人票）

| 項目 | 書くこと |
|---|---|
| `openings` | 募集人数（数字） |
| `employment`・`contract` | 雇用の形、契約の期間 |
| `salaryType` | `月給` か `時給` |
| `salaryMin`・`salaryMax` | 金額（数字だけ。カンマや「円」は付けない）。1つの金額なら同じ数字を2つ |
| `takeHome` | 手取りの目安（何を引いたあとか、も書く） |
| `bonus` | 賞与・昇給 |
| `hours`・`holidays`・`annualHolidays`・`overtime` | 勤務時間、休日、年間休日数（数字）、残業の目安 |
| `housing.available` | 寮・社宅があれば `true` |
| `housing.detail`・`rent`・`initialCost`・`commute` | 住まいの中身、家賃、初期費用、通勤方法 |
| `moving` | 引っ越しの支援 |
| `japanese` | 必要な日本語。`none`・`N5`・`JFT`・`N4`・`N3`・`N2`・`N1`（絞り込みに使います） |
| `japaneseText` | 日本語の条件の説明 |
| `requirements` | 必要な資格・経験 |
| `support`・`consultLanguages` | 入社後の支援、相談できる言語 |
| `visaSupport` | 在留資格の変更手続きを、会社か支援機関が手伝うか |
| `changeScope` | **就業場所・業務の変更の範囲**（雇入れ直後と、変わりうる範囲） |

**空の項目は、ページに出ません。** 分からない項目を、推測で埋めないでください。
